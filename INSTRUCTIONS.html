How to use

Windows(beta)

  1. For some god known reason, making a script to setup this program in windows just doesn’t seem to work
    so here are the instructions on how to install the required dependencies
  2. Download python3
  3. In the folder that you were given run the following command: 
    C:\Users\tibthink\reliqua2.0\client\python3 -m pip install -r .\requirements.txt
    If everything goes right you should be able to continue to step...
  4. In a new command prompt (unless python3 was already installed) run this command to run the main program: 
    C:\Users\tibthink\reliqua2.0> python3 reliqua_client.py
  5. The script should run after that, it will prompt you with a password,
    if you do not have the password, ask the person who sent you this and
    request the password.

Linux/MacOS

  1. Open a terminal and run the following command (you need sudo/root to run this): 
    tibthink@hal:~/reliqua2.0$ sudo ./setup.sh
  2. After that has completed successfully you are now ready to run the script
    by running the following command: 
    tibthink@hal:~/reliqua2.0$ python3 reliqua_client.py
  3. The script should run after that, it will prompt you with a password,
    if you do not have the password, ask the person who sent you this and
    request the password.
