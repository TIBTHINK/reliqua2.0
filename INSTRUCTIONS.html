How to use

Windows (beta)

  1. Open a command prompt as an admin and run the startup script:

    C:\Users\tibthnk\reliqua2.0> setup.bat

    If everything goes right you should be able to continue to the next step.

  2. In a new command prompt (unless Python 3 was already installed), run this command to start the main program:

    C:\Users\tibthink\reliqua2.0> python3 reliqua_client.py

  3. The script should run after that. It will prompt you for a password. If you do not have the password, ask the person who sent you this and request the password.

Linux/MacOS

  1. Open a terminal and run the following command (you need sudo/root privileges to run this):

    tibthink@hal:~/reliqua2.0$ sudo ./setup.sh

  2. After that has completed successfully, you are now ready to run the script by executing the following command:

    tibthink@hal:~/reliqua2.0$ python3 reliqua_client.py

  3. The script should run after that. It will prompt you for a password. If you do not have the password, ask the person who sent you this and request the password.
